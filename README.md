# استوديو التصوير + صور الحفلة بالباركود

موقع استوديو تصوير: صفحات تعريفية وباقات وحجز جلسات، ولوحة لصاحب الاستوديو، وميزة صور الحفلات بالباركود (الضيف يلتقط سيلفي فتظهر له صوره فقط) يستخدمها الاستوديو والمصورون المعتمدون.

## الصفحات

| الرابط | الوظيفة |
|---|---|
| `/` | الرئيسية |
| `/packages` | الباقات (تُدار من اللوحة) |
| `/book` | حجز جلسة واختيار الباقة والتاريخ (يحتاج حساب عميل) |
| `/login`, `/account` | حساب العميل: تسجيل بالجوال وكلمة سر، ومتابعة حجوزاته |
| `/gallery`, `/about` | المعرض ومن نحن |
| `/photographers` | طلب مصوّر لاستخدام ميزة الباركود |
| `/admin` | اللوحة: الحجوزات، جدول المواعيد، الباقات، الحفلات، المصورون |
| `/e/<رمز الحفلة>` | صفحة الضيف (سيلفي ← صوره) |

## الدخول للوحة

- **صاحب الاستوديو**: كلمة السر في `ADMIN_PASSWORD`. يرى كل شيء.
- **المصوّر**: ينشئ حسابه من `/photographers` (بريد وكلمة سر)، وبعد موافقة صاحب الاستوديو يظهر له زر الدخول. يرى حفلاته فقط.
- **العميل**: ينشئ حسابه بالجوال من `/login` أو عند الحجز، ويتابع حالة حجوزاته في `/account`. حساب العميل لا يفتح لوحة الإدارة.

## بيانات الاستوديو

عدّل `lib/site.ts`: الاسم، الجوال، العنوان، الأرقام وآراء العملاء. القيم الحالية أمثلة من التصميم.

## التشغيل محلياً

يحتاج Postgres مع إضافة pgvector:

```bash
npm install
DATABASE_URL=postgres://... ADMIN_PASSWORD=كلمة-سر npm run dev
```

## النشر على الإنترنت (Vercel)

1. ادخل [vercel.com](https://vercel.com) بحساب GitHub.
2. **Add New → Project** واختر المستودع `vision-2030` ثم **Deploy**.
3. من صفحة المشروع: **Storage → Create → Blob** واربطه بالمشروع (يضيف `BLOB_READ_WRITE_TOKEN`).
4. **Storage → Create → Neon (Postgres)** واربطه بالمشروع (يضيف `DATABASE_URL`). الجداول تُنشأ تلقائياً عند أول استخدام.
5. **Settings → Environment Variables**: أضف `ADMIN_PASSWORD` بكلمة سر قوية.
6. **Deployments → Redeploy** حتى تُطبَّق الإعدادات.

## كيف تعمل صور الحفلة

- اكتشاف الوجوه يتم في متصفح المصوّر قبل الرفع، ويُحفظ لكل وجه بصمة رقمية (128 رقماً) وليس صورة.
- **الرفع المباشر**: من صفحة الحفلة يختار المصوّر مجلد الكاميرا على الكمبيوتر، والصفحة ترفع كل صورة جديدة تلقائياً (Chrome أو Edge).
- **الضيف**: السيلفي لا يغادر الجوال؛ تُرسل البصمة فقط للمطابقة. الصفحة تتحدث كل 8 ثوانٍ.
- **الحذف التلقائي** بعد المدة التي يحددها المصوّر.

| الملف | الوظيفة |
|---|---|
| `lib/db.ts` | الاتصال بقاعدة البيانات وإنشاء الجداول |
| `lib/studio.ts` | الباقات والحجوزات والمصورون |
| `lib/auth.ts` | الدخول (صاحب الاستوديو / مصوّر / عميل) |
| `lib/clients.ts` | حسابات العملاء |
| `lib/store/postgres.ts` | الحفلات والصور وبصمات الوجوه (pgvector) |
| `lib/files.ts` | الصور على Vercel Blob، أو على القرص محلياً |
| `lib/face-client.ts` | اكتشاف الوجوه في المتصفح (face-api) |
| `lib/site.ts` | بيانات الاستوديو المعروضة في الموقع |
