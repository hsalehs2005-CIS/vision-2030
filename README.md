# صور الحفلة

موقع للأعراس والحفلات: المصوّر يرفع الصور، والضيف يصوّر الباركود ويلتقط سيلفي، فتظهر له الصور التي يظهر فيها فقط.

## التشغيل محلياً

```bash
npm install
ADMIN_PASSWORD=كلمة-سر npm run dev
```

ثم افتح `http://localhost:3000/admin`.

## كيف يعمل

- **المصوّر** (`/admin`): ينشئ حفلة، يرفع الصور، ويحمّل الباركود للطباعة. اكتشاف الوجوه يتم في متصفح المصوّر قبل الرفع، ويُحفظ لكل وجه بصمة رقمية (128 رقماً) وليس صورة.
- **الرفع المباشر**: من صفحة الحفلة يختار المصوّر مجلد الكاميرا على الكمبيوتر (المجلد الذي يحفظ فيه برنامج الكاميرا الصور عبر Wi‑Fi أو الكيبل، مثل Canon EOS Utility أو Sony Imaging Edge أو Nikon NX Tether). الصفحة تفحص المجلد كل 3 ثوانٍ وترفع كل صورة جديدة تلقائياً. يعمل على Chrome أو Edge.
- **الضيف** (`/e/<رمز الحفلة>`): يوافق على الشروط، يلتقط سيلفي، والمتصفح يستخرج بصمة وجهه ويرسلها للخادم للمطابقة. **السيلفي نفسه لا يغادر الجوال.** صفحة الضيف تتحدث تلقائياً كل 8 ثوانٍ وتنبّهه عند وصول صور جديدة له.
- **الحذف التلقائي**: كل حفلة تُحذف مع صورها وبصمات الوجوه بعد المدة التي يحددها المصوّر.

## البنية

| الملف | الوظيفة |
|---|---|
| `lib/face-client.ts` | اكتشاف الوجوه في المتصفح (face-api) |
| `lib/match.ts` | مطابقة البصمات (المسافة أقل من 0.5) |
| `lib/store.ts` | التخزين، حالياً ملفات على القرص في `data/` |
| `lib/auth.ts` | دخول المصوّر بكلمة سر |

## للانتقال للإنتاج

- استبدال `lib/store.ts` بتخزين سحابي (Cloudflare R2 أو S3) وقاعدة بيانات Postgres.
- خيار تبديل المطابقة إلى AWS Rekognition لدقة أعلى مع الحفلات الكبيرة.
- حسابات متعددة للمصورين ونظام دفع.
